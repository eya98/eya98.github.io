Tissue segmentation on gigapixel slides, for BioNTech

A single H&E slide can be close to 90,000 pixels on a side. The model labels tissue regions across the whole slide and runs in production on the client's platform. I was a core engineer on the team and owned the deployment. Scroll through the build.

  1. A data loader for gigapixel slides

    I built the project's first whole-slide data loader. It reads the slide's microns per pixel and picks the matching pyramid level, so the model reads a downsampled level directly instead of resizing full-resolution tiles. Later training pipelines were built on it.

  2. Swappable foundation-model backbones

    I made the ViT foundation-model backbones configurable, so any of them can sit behind the same segmentation head. One config change swaps the backbone, which is what made the benchmark below possible.

  3. A better head: Mask2Former

    I proposed replacing the previous segmentation head with Mask2Former and implemented it with a teammate.

    IoU 72 → 81.6

  4. Finding the fine-tuning bug

    The ViT-Adapter fine-tuning had a bug. I found and fixed it, and the same architecture gained almost ten points of IoU.

    IoU 81.6 → 91.4

  5. Shipping it

    I owned the PyTorch to ONNX deployment for production inference on the client's platform, with an automated check that the ONNX outputs match PyTorch. I ran the technical deployment sessions with the BioNTech team and worked directly with their pathologists.

Model selection

Which backbone? A controlled comparison

Five frozen ViT foundation models behind one shared ViT-Adapter and Mask2Former head, so the backbone was the only variable. Four pathology-specific models and the general-purpose DINOv3. Hibou-B had the best IoU and became the project's backbone.

Slide-level prediction

Predicting microsatellite instability

MSI is a tumor biomarker used to guide immunotherapy. I co-developed the first version of a LongViT model that predicts it from the whole slide. Against three external vendors, it ranked first in recall and second in accuracy and F1-score. Another team then took it further.

Foundation-model embeddings

Flagging failed lab sample preparation

I extracted tile- and slide-level Prov-GigaPath embeddings from 1,195 whole-slide images to feed a LightGBM classifier predicting which library preparations would fail. Pooling embeddings by tissue type, using the segmentation output, lowered the false positives. Tumor tissue clustered best.

Jan to Jun 2023 · reinforcement learning

Decision Transformer for bin packing

A six-month research topic in a four-person team. We co-developed a GPT-2 Decision Transformer trained on 1.5TB of trajectories from the production SPPO agent. It beat SPPO on 1 of 45 instances. An XGBoost probe then showed why: the raw states carried the signal, the embedded states lost it, so the bottleneck was the state embeddings.
